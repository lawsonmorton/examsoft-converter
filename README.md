# ExamSoft Smart Converter

Converts exam questions from PDF (including scanned), Word, RTF, CSV, Blackboard and text files into an RTF file ready for ExamSoft import.

Published by **Etechtronics**.

## Download
**[Download the latest version](https://github.com/lawsonmorton/examsoft-converter/releases/latest/download/ExamSoftConverter_Setup.exe)** (Windows 10/11)

Includes a 21-day free trial. A yearly license key is available at https://mortonlawson0.gumroad.com/l/iopyro

## Updates
The program checks for updates when it opens. You can also check any time from **Help → Check for Updates**. Your question bank and license are kept when you update.
